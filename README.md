# Tungsten Emulator
Tungsten Emulator is a feature‍-‍rich, browser‍-‍based retro-game emulator that can run games (and ROM hacks) from 16+ consoles. Dump game data, load ROM files, and start playing.

---

## Support for 16+ Consoles
With emulation powered by WASM-RetroArch, you can emulate games at a reasonable FPS from 16+ different* consoles, including but not limited to the **NES**, **SNES**, **Nintendo 64**, **Nintendo DS**, **SEGA MegaDrive**, **Atari**, etc.

---

## Controller Support
All games have controller support just like the original. Just connect a controller via Bluetooth or USB‍-‍A / USB‍-‍C and you should be able to connect a controller to the game.

---

## Save States
You can have up to **nine** save states at any given time for any game, and you can also choose to inject save states (usually `.sav` or `.srm` files).

Cloud synced save states are coming soon, so stay tuned for that.
