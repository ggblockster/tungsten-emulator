Dump, Load, Play.

Tungsten Emulator is a feature‍-‍rich, browser‍-‍based retro-game emulator that can run games (and ROM hacks) from 16+ consoles. Dump game data, load ROM files, and start playing.

Support for 16+ Consoles

With emulation powered by WASM-RetroArch, you can emulate games at a reasonable FPS from 16+ different* consoles, including but not limited to the NES, SNES, N64, Nintendo DS, SEGA MegaDrive, Atari, etc.

Familiar UI

Tungsten's UI is structured similar to Steam Desktop's, so it should be easy to use.

There are a variety of themes to choose from, so you can choose an appearance that works for you.

Controller Support

Tungsten Emulator also has controller support, so you can simply connect a controller (USB or Bluetooth) and start using it right away.

Save States

You can have up to nine save files at any given time for any game, and you can also choose to inject save files (usually .sav or .srm files). Cloud synced save files are coming soon, so stay tuned for that.

BUT THAT'S NOT ALL!

There are still so much more features that haven't already been mentioned above.
